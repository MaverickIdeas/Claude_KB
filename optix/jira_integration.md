### Using the CLI from agent tool-calls (IMPORTANT)
The Bash and PowerShell tools run non-interactively and do **NOT load shell profiles** (`~/.bashrc`, `$PROFILE`) and do NOT inherit the stale harness's missing PATH/token. So a bare `jira` fails. **Activate first:**
- Bash: `source ~/.config/.jira/activate.sh && jira <cmd>`
- PowerShell: `. "$env:USERPROFILE\.config\.jira\activate.ps1"; jira <cmd>`
Activation = add bin to PATH + load creds from `~/.config/.jira/credentials.env` (0600, holds BASE_URL/EMAIL/TOKEN). A freshly-launched session inherits User-scope PATH+token and can skip activation. Global note added to `~/.claude/CLAUDE.md` so all sessions know. Verified `jira issue create`/`delete` work after activation.
